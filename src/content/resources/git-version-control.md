Git is a foundation for transparent and reproducible research software. The official documentation includes installation guidance, reference material, videos, and the complete *Pro Git* book.

SPARK plans to connect version control with practical questions researchers encounter every day: how to organize a scientific repository, document changes, collaborate safely, and prepare work for reuse.

## Why it matters

- Preserve a traceable history of changes.
- Collaborate without overwriting one another's work.
- Connect code changes to scientific decisions.
- Make research artifacts easier to inspect, reproduce, and maintain.
